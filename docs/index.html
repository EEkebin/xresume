xresume

Resume any coding-agent conversation in the CLI it came from, or carry it into another one with its full history. Works with Claude Code, Codex CLI, Antigravity CLI, OpenCode and Grok CLI.

curl -fsSL https://eekebin.github.io/xresume/install.sh | bash

Paste into a terminal. Installs one file to ~/.local/bin; nothing else is needed.

What it does

  • One list for every conversationEvery CLI in one place, newest first. Press / to search by title, folder or id. Enter resumes where the conversation lives.
  • Move a conversation between CLIsPress Right, pick the CLI from the menu, press Enter. xresume writes a real session in the other CLI's own format, with messages, tool calls and tool results, and opens it with that CLI's own resume.
  • Back to the list when you quitLeave a CLI and xresume reopens, so hopping from one CLI to another is quit, Right, pick, Enter.
  • Preview before you openPress Space for a side panel with the last few messages of the selected conversation, so you know it is the right one.
  • One session per CLI, kept in stepMove a conversation back later and only the new turns are added to the copy already there. Each conversation shows as one row.
  • Backups before any changeBefore adding to an existing session, a copy is saved in ~/.xresume/backups.

Keys

↑ ↓Move. PgUp, PgDn, Home and End work too.
/Search by title, folder, tool or id. Esc cancels the search.
EnterResume in the CLI the conversation came from.
→Open in another CLI. A menu lists them with the current one first; Up and Down choose, Enter opens, Esc closes it.
SpaceShow or hide the preview panel. p works too; while searching, use Ctrl+P.
TabLaunch with the CLI's skip-permissions flags. The footer shows exactly which.
EscExit. Ctrl+C twice also exits.
MouseClick selects, double-click opens, wheel scrolls.

Good to know

Antigravity's conversation format is undocumented, so support follows what agy 1.5 writes and an update may break it; Grok support likewise follows Grok CLI 1.0. OpenCode cannot add turns to an existing session, so a conversation moved back into it becomes a new OpenCode session. Hidden reasoning is not carried between CLIs, Codex redraws imported messages but not imported tool calls (the model still has them), and tool outputs longer than 6,000 characters are trimmed. Tested on Windows and Linux; macOS shares the Linux code but is untested by hand. The installers fetch a standalone executable for Windows x64, Linux x64 and arm64, and Apple Silicon Macs; other systems get the Python version, which needs Python 3.8 or newer.
